Questions

Short answers to common ones.

Which interview types are supported?

Behavioral, technical, system design, product sense and case interviews, for any role you type in.

Do I need to upload my resume?

No, but questions and feedback become much more specific when you do.

Does voice practice work in every browser?

Voice input uses the browser's speech recognition, which works best in Chrome and Edge. You can always type instead.

Is this meant for live interviews?

Poised is a practice tool. Use it to rehearse before the interview so you can answer on your own when it counts.
